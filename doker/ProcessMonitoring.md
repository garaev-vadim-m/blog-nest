## Process Monitoring

#### Смотрим процессы

```bash
ps aux
```

##### Наблюдатель

```bash
watch -n 1 'ps aux'
```

Важные моменты:

`PID 1` — особый процесс. В контейнере это главный процесс — если он умрёт, контейнер остановится.

`TIME` — сколько CPU времени процесс потратил суммарно.

Дерево процессов (пример) — `dev.sh` → `npm` → `npm exec` → `node nest` → `node main`.

#### Дерево процессов

```bash
ps aux --forest
```

#### Дерево процессов нагляднее

```bash
pstree -p
```

#### Монитор процессов

```bash
top
```

#### Убить процесс жестко

```bash
kill -9
```

#### Убить процесс мягко

```bash
kill -15
```

`kill -15 (SIGTERM)` → мягко, процесс завершается сам

`kill -9  (SIGKILL)` → жёстко, ядро убивает принудительно

`PID 1 в контейнере` → главный процесс, умер = контейнер упал

`pstree -p ` → дерево процессов

`top` → живой мониторинг ресурсов

`ps aux` → снимок всех процессов
